# 多项目架构方案：小程序 + 网页共享后端

## 🎯 你的问题

你有两个扣子项目：
1. **小程序项目**（当前这个）
2. **网页项目**（https://3dkskbjf2r.coze.site）

你想让两个项目都访问同一个 FastAPI 后端。

## ❌ 问题：扣子平台项目隔离

**扣子平台的每个项目是独立的**：
- 项目A的后端（端口 3000）只能在项目A内部访问
- 项目B无法直接访问项目A的后端
- 项目之间是隔离的，不能直接通信

```
扣子平台
├── 小程序项目
│   ├── 前端（端口 5000）
│   └── 后端（端口 3000）← 网页项目无法直接访问
│
└── 网页项目
    ├── 前端（端口 5000）
    └── 后端（端口 3000）← 小程序项目无法直接访问
```

## ✅ 解决方案：后端独立部署

**推荐方案**：将你的 FastAPI 后端独立部署到公网，两个项目都通过公网访问。

```
你的 FastAPI 后端（独立部署）
↓
https://your-api.railway.app
↓
┌─────────────┬─────────────┐
│             │             │
↓             ↓             ↓
小程序项目   网页项目    其他项目
(扣子平台)   (扣子平台)  (未来扩展)
```

### 优势

- ✅ 两个项目都能访问
- ✅ 后端统一管理
- ✅ 数据一致
- ✅ 易于扩展（未来可以加更多项目）

## 🚀 快速部署到 Railway（5分钟）

### 步骤 1：准备你的 FastAPI 项目

确保你的 FastAPI 项目结构如下：

```
your-fastapi-project/
├── main.py
├── requirements.txt
├── Procfile
└── runtime.txt
```

**main.py 示例**：
```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()

# 允许跨域（重要！）
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # 允许所有来源
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

@app.get("/")
async def root():
    return {"message": "Hello World"}

@app.get("/api/health")
async def health():
    return {"status": "ok"}

# 你的软著接口
@app.post("/api/software-copyright/form")
async def create_form(data: dict):
    # 你的业务逻辑
    return {"code": 200, "data": {"query_code": "RJ20260521xxx"}}
```

**requirements.txt**：
```
fastapi==0.104.1
uvicorn==0.24.0
python-multipart==0.0.6
```

**Procfile**：
```
web: uvicorn main:app --host 0.0.0.0 --port $PORT
```

**runtime.txt**：
```
python-3.11.0
```

### 步骤 2：部署到 Railway

**方法A：使用 GitHub（推荐）**

1. 将你的 FastAPI 项目推送到 GitHub
2. 访问 https://railway.app/
3. 点击 "Start a New Project"
4. 选择 "Deploy from GitHub repo"
5. 选择你的仓库
6. 点击 "Deploy"

**方法B：使用 Railway CLI**

```bash
# 1. 安装 Railway CLI
npm install -g @railway/cli

# 2. 登录
railway login

# 3. 初始化项目
railway init

# 4. 部署
railway up

# 5. 查看日志
railway logs
```

### 步骤 3：获取公网地址

部署成功后，Railway 会自动分配一个域名：

```
https://your-app.up.railway.app
```

### 步骤 4：在扣子项目中配置

**小程序项目**：

修改 `/workspace/projects/config/index.ts`：

```typescript
proxy: {
  '/api': {
    target: 'https://your-app.up.railway.app',
    changeOrigin: true,
  },
},
```

或者在环境变量中配置：
```bash
SOFTREG_API_URL=https://web-production-2c115.up.railway.app
```

**网页项目**：

在你的网页项目中，直接调用这个地址：

```javascript
const response = await fetch('https://web-production-2c115.up.railway.app');
```

## 🔧 高级配置

### 1. 自定义域名（可选）

在 Railway 设置中添加自定义域名：
```
api.yourdomain.com
```

### 2. 环境变量

在 Railway 设置中添加环境变量：
```
DATABASE_URL=your_database_url
SECRET_KEY=your_secret_key
```

### 3. 数据库

Railway 支持多种数据库：
- PostgreSQL
- MySQL
- Redis
- MongoDB

点击 "Add Service" → 选择数据库 → 自动获取连接地址。

