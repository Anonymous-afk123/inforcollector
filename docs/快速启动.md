# 快速启动：本地后端连接扣子平台

## 🚀 最快方法（5分钟）

### 步骤 1：安装 ngrok

```bash
# macOS
brew install ngrok

# Windows
# 下载 https://ngrok.com/download
```

### 步骤 2：注册 ngrok 账号（免费）

访问 https://ngrok.com/ 注册，获取 authtoken。

### 步骤 3：配置 ngrok

```bash
ngrok config add-authtoken your_token_here
```

### 步骤 4：启动你的 FastAPI 后端

```bash
# 在你的本地后端文件夹
uvicorn main:app --reload --port 8000
```

### 步骤 5：启动 ngrok

```bash
ngrok http 8000
```

你会看到类似输出：
```
Forwarding  https://abc123.ngrok.io -> http://localhost:8000
```

### 步骤 6：复制 https 地址

复制上面的 `https://abc123.ngrok.io`（你的地址会不同）。

### 步骤 7：在扣子平台配置环境变量

在扣子平台的环境变量配置中添加：

```
PROJECT_DOMAIN=https://abc123.ngrok.io
SOFTREG_API_URL=https://abc123.ngrok.io
```

### 步骤 8：测试

在扣子平台的小程序中：
1. 填写采集表
2. 提交
3. 查询数据

## ✅ 完成！

现在扣子平台的小程序和网页都能访问你的本地后端了。

## 📝 注意事项

- **ngrok 免费版**：每次重启域名会变化，需要重新配置
- **适合开发测试**：生产环境建议部署到 Railway 或云服务器
- **HTTPS 要求**：小程序要求 HTTPS，ngrok 默认提供

## 🔄 如果域名变了

重新启动 ngrok 后：
1. 复制新的 https 地址
2. 更新扣子平台的环境变量
3. 重新测试

## 📦 长期方案：部署到 Railway

测试成功后，建议部署到 Railway（免费 + 固定域名）：

```bash
# 1. 安装 Railway CLI
npm install -g @railway/cli

# 2. 登录
railway login

# 3. 部署
railway up

# 你会得到一个固定域名
# https://your-app.up.railway.app
```
