# 📝 扣子编程网页集成指南（超详细版）

## 核心概念

**为什么网页输入查询码能获取小程序的数据？**
- 因为小程序和网页访问的是**同一个数据库**
- 查询码就是数据库中这条记录的唯一标识
- 就像快递单号一样，输入单号就能查询快递信息

## 实现步骤

### 第一步：部署后端到公网

你需要将后端部署到公网，让扣子编程的网页能访问到。

**选择一：使用云服务器**
1. 购买云服务器（阿里云、腾讯云等）
2. 安装 Node.js
3. 上传代码并启动服务
4. 配置域名和 HTTPS

**选择二：使用 Serverless 平台（推荐）**
- Vercel: https://vercel.com
- Railway: https://railway.app
- Render: https://render.com

部署后你会得到一个公网地址，例如：
```
https://your-backend.vercel.app
```

### 第二步：在扣子编程中添加查询功能

#### 方法一：使用扣子编程的 HTTP Request 节点

1. **添加输入框**
   - 在扣子编程的工作流中添加一个文本输入框
   - 变量名：`queryCode`
   - 提示语：请输入查询码

2. **添加 HTTP Request 节点**
   - Method: GET
   - URL: `https://你的后端域名/api/software-copyright/query/{{queryCode}}`
   - 示例：`https://your-backend.vercel.app/api/software-copyright/query/RJ20260519543`

3. **处理返回数据**
   - 接口返回格式：
   ```json
   {
     "code": 200,
     "msg": "查询成功",
     "data": {
       "query_code": "RJ20260519543",
       "software_full_name": "测试软件系统",
       "version": "V1.0",
       "software_category": "应用软件",
       "development_date": "2024-01-01",
       "development_tools": "VS Code",
       "programming_language": "JavaScript",
       "source_code_lines": 10000,
       "main_functions": "主要功能描述...",
       "technical_features": "技术特点...",
       "company_name": "公司名称",
       "credit_code": "统一社会信用代码"
     }
   }
   ```

4. **展示数据**
   - 使用文本节点展示查询结果
   - 或者传递给你的文档生成模块

#### 方法二：使用自定义代码节点

如果你的扣子编程支持自定义代码，可以直接使用这段代码：

```javascript
async function queryForm(queryCode) {
  // 替换为你的后端域名
  const backendUrl = 'https://your-backend.vercel.app';
  
  try {
    const response = await fetch(`${backendUrl}/api/software-copyright/query/${queryCode}`);
    const result = await response.json();
    
    if (result.code === 200) {
      // 查询成功，返回数据
      return {
        success: true,
        data: result.data
      };
    } else {
      // 查询失败
      return {
        success: false,
        message: result.msg
      };
    }
  } catch (error) {
    return {
      success: false,
      message: '网络错误，请稍后重试'
    };
  }
}
```

### 第三步：完整示例

#### 示例1：简单的查询页面

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>软著采集表查询</title>
</head>
<body>
  <h1>查询软著采集表</h1>
  
  <input type="text" id="queryCode" placeholder="请输入查询码">
  <button onclick="query()">查询</button>
  
  <div id="result"></div>

  <script>
    async function query() {
      const queryCode = document.getElementById('queryCode').value.trim();
      
      if (!queryCode) {
        alert('请输入查询码');
        return;
      }
      
      // 替换为你的后端域名
      const backendUrl = 'https://your-backend.vercel.app';
      
      try {
        const response = await fetch(`${backendUrl}/api/software-copyright/query/${queryCode}`);
        const result = await response.json();
        
        if (result.code === 200) {
          // 查询成功，显示数据
          const data = result.data;
          document.getElementById('result').innerHTML = `
            <h2>查询成功</h2>
            <p><strong>软件名称：</strong>${data.software_full_name}</p>
            <p><strong>版本号：</strong>${data.version}</p>
            <p><strong>开发工具：</strong>${data.development_tools}</p>
            <p><strong>编程语言：</strong>${data.programming_language}</p>
            <p><strong>代码行数：</strong>${data.source_code_lines} 行</p>
            <p><strong>主要功能：</strong>${data.main_functions}</p>
          `;
        } else {
          alert('查询失败：' + result.msg);
        }
      } catch (error) {
        alert('网络错误，请稍后重试');
        console.error(error);
      }
    }
  </script>
</body>
</html>
```

#### 示例2：集成到你的扣子编程工作流

假设你的扣子编程工作流如下：
1. 用户上传 MD 文件 → 解析 → 生成文档

现在改为：
1. 用户输入查询码 → 调用接口获取数据 → 生成文档

**具体操作**：

1. **删除原有的"上传文件"节点**
2. **添加"文本输入"节点**
   - 提示语：请输入查询码
   - 变量名：queryCode
3. **添加"HTTP Request"节点**
   - URL: `https://your-backend.vercel.app/api/software-copyright/query/{{queryCode}}`
   - Method: GET
   - 保存结果到变量：formData
4. **修改文档生成节点**
   - 使用 `formData.data` 中的数据
   - 例如：`{{formData.data.software_full_name}}`

## 常见问题

### Q1: 后端域名是什么？
A: 后端域名是你部署后端服务后的公网地址。如果你还没部署，可以先在本地测试：
- 本地地址：http://localhost:3000
- 但扣子编程无法访问本地地址，所以必须部署到公网

### Q2: 如何测试接口？
A: 你可以用浏览器直接访问：
```
http://localhost:3000/api/software-copyright/query/RJ20260519543
```
如果返回 JSON 数据，说明接口正常。

### Q3: 查询码从哪里来？
A: 用户在小程序填写采集表后，会自动生成查询码并显示给用户。

### Q4: 扣子编程如何调用外部接口？
A: 扣子编程支持 HTTP Request 节点，可以调用任何外部 API。具体操作：
1. 在工作流中添加"HTTP Request"节点
2. 配置 URL、Method、Headers 等
3. 将返回结果保存到变量
4. 在后续节点中使用这个变量
