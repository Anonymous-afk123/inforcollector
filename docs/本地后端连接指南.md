# 本地后端连接扣子平台指南

## 问题说明

扣子平台是云端服务，小程序和网页都在云端运行，无法直接访问你本地的 `localhost:8000`。

## 解决方案

### 方案一：内网穿透（推荐，快速测试）

#### 1. 使用 ngrok（最简单）

**步骤**：

```bash
# 1. 安装 ngrok
# macOS
brew install ngrok

# Windows
# 下载 https://ngrok.com/download

# 2. 注册账号（免费）
# 访问 https://ngrok.com/ 注册

# 3. 配置 authtoken
ngrok config add-authtoken your_token_here

# 4. 启动内网穿透
ngrok http 8000

# 5. 你会看到类似输出：
# Forwarding  https://abc123.ngrok.io -> http://localhost:8000
```

**复制 https 地址**（如 `https://abc123.ngrok.io`），这就是你的公网地址。

#### 2. 使用 localtunnel（完全免费）

```bash
# 1. 安装
npm install -g localtunnel

# 2. 启动
lt --port 8000

# 3. 你会看到类似输出：
# your url is: https://random-name.loca.lt
```

**注意**：localtunnel 首次访问需要输入 IP 地址验证，输入你的 IP 即可。

#### 3. 使用 frp（需要自己搭建服务器）

如果你有自己的云服务器，可以使用 frp。

### 方案二：部署后端到公网（长期方案）

#### 1. Railway（推荐）

```bash
# 1. 安装 Railway CLI
npm install -g @railway/cli

# 2. 登录
railway login

# 3. 初始化项目
railway init

# 4. 部署
railway up

# 5. 你会得到一个域名
# https://your-app.up.railway.app
```

#### 2. Vercel（FastAPI 需要特殊配置）

```bash
# 1. 安装 Vercel CLI
npm install -g vercel

# 2. 登录
vercel login

# 3. 部署
vercel
```

#### 3. 自己的云服务器

如果你有云服务器（阿里云、腾讯云等），直接部署即可。

### 方案三：使用扣子平台的本地开发模式

扣子平台支持本地开发，可以让云端小程序访问你的本地后端。

## 配置步骤

### 1. 获取公网地址

假设你使用 ngrok，得到了：`https://abc123.ngrok.io`

### 2. 配置环境变量

在扣子平台上配置环境变量：

```bash
# .env
PROJECT_DOMAIN=https://abc123.ngrok.io
SOFTREG_API_URL=https://abc123.ngrok.io
```

### 3. 修改前端代码

确保前端请求使用正确的域名：

```typescript
// src/network/index.ts
const BASE_URL = process.env.PROJECT_DOMAIN || 'http://localhost:8000';

// 所有请求都会自动添加 BASE_URL
Network.request({
  url: '/api/your-endpoint', // 会变成 https://abc123.ngrok.io/api/your-endpoint
});
```

### 4. 测试连接

```bash
# 测试后端是否可访问
curl https://abc123.ngrok.io/api/health

# 或者测试具体接口
curl https://abc123.ngrok.io/api/software-copyright/query/RJ20260519543
```

## 注意事项

### 1. CORS 配置

你的 FastAPI 后端需要允许跨域请求：

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # 生产环境应该限制具体域名
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### 2. HTTPS 要求

小程序要求 HTTPS，ngrok 和 Railway 默认提供 HTTPS，无需额外配置。

### 3. 域名变化

- **ngrok 免费版**：每次重启域名会变化，需要重新配置
- **ngrok 付费版**：可以固定域名
- **Railway**：域名固定不变

### 4. 稳定性

- **内网穿透**：适合开发测试，不适合生产环境
- **云部署**：适合生产环境

## 快速开始（推荐流程）

1. **启动本地 FastAPI 后端**
   ```bash
   uvicorn main:app --reload --port 8000
   ```

2. **启动 ngrok**
   ```bash
   ngrok http 8000
   ```

3. **复制 https 地址**
   - 例如：`https://abc123.ngrok.io`

4. **在扣子平台配置环境变量**
   - `PROJECT_DOMAIN=https://abc123.ngrok.io`
   - `SOFTREG_API_URL=https://abc123.ngrok.io`

5. **测试小程序和网页**
   - 填写采集表
   - 查询数据
   - 生成文档

6. **如果测试成功，部署到 Railway 或自己的云服务器**

## 常见问题

### Q: ngrok 域名每次都变怎么办？
A: 免费版就是这样，建议测试完成后部署到 Railway（免费且有固定域名）。

### Q: 小程序提示"request:fail"？
A: 检查：
1. 后端是否启动
2. ngrok 是否运行
3. 环境变量是否配置正确
4. CORS 是否允许跨域

### Q: 网页可以访问，小程序不行？
A: 小程序要求 HTTPS，确保使用 ngrok 的 https 地址，而不是 http。

### Q: 如何让团队其他成员访问？
A: 部署到 Railway 或云服务器，分享公网地址即可。
