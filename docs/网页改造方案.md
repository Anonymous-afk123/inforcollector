# 🎯 扣子编程网页改造方案

## 方案概述

使用**查询码**方案，让用户在小程序填写采集表后获取查询码，然后在网页端输入查询码查询数据。

### 优势
- ✅ 不需要微信公众号
- ✅ 不需要短信服务
- ✅ 不需要手机号绑定
- ✅ 简单直接，用户体验好

```
POST /api/software-copyright/form
```

```json
  }
```

### 2. 查询码查询接口（已实现）

```
GET /api/software-copyright/query/:code
```

## 网页端改造步骤

### 方法一：在扣子编程中添加查询功能

1. **添加输入框**：在扣子编程的工作流中添加一个输入框，让用户输入查询码

2. **调用后端接口**：使用 HTTP Request 节点调用查询接口
   - URL: `你的后端域名/api/software-copyright/query/${查询码}`
   - Method: GET

3. **处理响应数据**：将查询结果展示给用户，或者传递给文档生成模块

### 方法二：创建独立的查询页面

我已经为你准备了一个独立的查询页面 `query-page.html`，你可以：

1. 直接部署这个 HTML 文件
2. 或者将代码复制到扣子编程中

**关键代码**：

```html
<!-- 输入框 -->
<input type="text" id="queryCode" placeholder="请输入查询码">

<!-- 查询按钮 -->
<button onclick="queryForm()">查询</button>

<!-- 查询结果 -->
<div id="result"></div>

<script>
async function queryForm() {
  const queryCode = document.getElementById('queryCode').value.trim();
  
  // 调用后端接口
  const response = await fetch(`你的后端域名/api/software-copyright/query/${queryCode}`);
  const result = await response.json();
  
  if (result.code === 200) {
    // 查询成功，显示数据
    const data = result.data;
    console.log('查询到的数据：', data);
    
    // 你可以在这里调用你的文档生成逻辑
    // 例如：generateDocument(data);
  } else {
    alert('查询码不存在或已过期');
  }
}
</script>
```

## 小程序端使用说明

1. 用户在小程序填写采集表
2. 提交成功后，会自动弹窗显示查询码
3. 用户可以点击"复制查询码"按钮复制到剪贴板
4. 用户在网页端输入查询码即可查询数据

## 后端域名配置

你需要将后端部署到公网，并将示例代码中的 `你的后端域名` 替换为实际的域名。

**开发环境**：
- 前端：http://localhost:5000
- 后端：http://localhost:3000

**生产环境**：
- 前端：你的小程序域名
- 后端：你的服务器域名（需要公网访问）

## 常见问题

### Q1: 查询码会重复吗？
A: 不会。查询码格式为 "RJ + 日期 + 3位随机数"，每天最多支持 1000 个查询码，足够使用。

### Q2: 查询码有有效期吗？
A: 目前没有设置有效期，只要数据库中存在就能查询。

### Q3: 如果用户忘记查询码怎么办？
A: 用户可以在小程序的"历史记录"中查看之前填写的采集表，每个采集表都会显示查询码。
